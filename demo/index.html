4What happened under the hood

🔐 Encrypted

Every transfer runs over TLS. The receiver's certificate fingerprint is pinned on first use, so a middleman can't silently intercept.

🪪 Mutual auth

The sender proves it holds its private key by signing a challenge bound to the receiver's fingerprint — replaying it elsewhere fails.

✅ Verified

SHA-256 of the received bytes must match the sender's checksum before the file is released into the inbox. One flipped bit → rejected.

👤 Human gate

Unknown devices land as pending requests. Nothing downloads until someone taps Accept — on the CLI or in this dashboard.

5Try it yourself

Python 3.10+, no dependencies beyond the standard library for the core:

$ git clone <repo> && cd openbeam $ python -m openbeam serve # receiving device $ python -m openbeam send photo.jpg # sending device — finds peers itself on a real LAN

On a real LAN, devices discover each other over mDNS (_openbeam._tcp.local.) — no --to needed. Phones join through the dashboard URL. Full protocol spec: docs/PROTOCOL.md in the repo.
