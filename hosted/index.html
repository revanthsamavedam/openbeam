How it works

Live: 1. Sender picks a file and gets a 6-letter code.
2. Receiver enters the code here — the sender sees the request and taps Accept (nothing moves without approval, same as openbeam on your Wi-Fi).
3. The file streams directly between the two browsers, encrypted by WebRTC (DTLS), and the receiver checks its SHA-256 before saving it.
Drop: the file is uploaded to storage with its own code and checksum, held for 24 hours, then deleted. The receiver just needs the code or link — no timing coordination.

On the same Wi-Fi? The original openbeam CLI is faster and needs no internet at all: github.com/revanthsamavedam/openbeam

openbeam online · live files are never stored on a server (practical limit ~500 MB — the file is held in memory on both devices) · drops up to 1 GB, held 24 hours · some strict corporate networks block direct browser-to-browser connections — use Drop there
